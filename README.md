# Blazor DataGrid - Customize Filter Popup Using CSS

## Overview

This sample demonstrates how to customize the filter dialog popup dimensions for specific columns in the Syncfusion Blazor DataGrid by using CSS. The implementation focuses on modifying the appearance of the Excel-style filter popup, allowing developers to control the width and height of the filter dialog independently from the default DataGrid styling. This approach is useful when filter content requires additional display space or when application-specific design requirements mandate customized filter dialog dimensions. The sample provides a practical reference for adjusting filter popup presentation without modifying the DataGrid filtering functionality.

## Key Features

- Demonstrates customization of the Syncfusion Blazor DataGrid filter dialog popup using CSS.
- Shows how to modify the width of filter popups for specific DataGrid columns.
- Demonstrates how to control filter popup height for improved usability.
- Uses CSS styling techniques to customize filter UI presentation without affecting filtering behavior.
- Provides a practical example of targeting DataGrid filter dialog elements through custom styles.
- Focuses specifically on filter popup appearance rather than custom filter logic.
- Maintains the built-in Syncfusion DataGrid filtering functionality while applying custom visual styling.
- Serves as a reference implementation for UI customization scenarios involving DataGrid filtering components.

## Prerequisites

- Visual Studio 2022 or Visual Studio Code
- .NET SDK compatible with the project's target framework

## How to Run the Project

**Visual Studio 2022**

1. Clone or download the repository.
2. Open the solution file `CustomFilterPopup.sln`.
3. Restore all NuGet packages.
4. Set the `CustomFilterPopup` project as the startup project if required.
5. Build the solution.
6. Run the application using `Ctrl+F5`.

**Visual Studio Code**

1. Open the repository folder in Visual Studio Code.
2. Open the integrated terminal.
3. Navigate to the project directory.

```bash
dotnet restore
dotnet run
```

4. Open the local URL displayed in the terminal after the application starts.
